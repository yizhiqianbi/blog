博客开张：先让写作发生

很多博客项目会从主题、插件、评论系统和发布流程开始，最后反而还没有真正写下一篇文章。 这个版本刻意把技术栈压到最低：一个 HTML 文件，一个 CSS 文件，推到 GitHub Pages 后就能访问。

后续可以把这里当作自己的公开笔记本。技术问题、项目复盘、阅读摘要、生活观察，都可以先写成短文。 当文章多起来，再把它升级成更完整的博客系统也不迟。
