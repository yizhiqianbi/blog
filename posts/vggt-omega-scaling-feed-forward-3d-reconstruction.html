这篇论文不是只提出一个小模块,而是把 VGGT 推到可扩展 3D/4D 几何基础模型的一次系统升级:架构省显存,数据管线扩大监督规模,自监督吃未标注视频,再证明 scene registers 可以服务 VLA 和语言对齐。

0一句话结论

痛点. VGGT 这类前馈 3D 重建模型已经很强,但训练显存、dense head 冗余、动态视频标注和未标注视频利用都卡住了继续 scaling。

核心招. VGGT-Ω 用 scene registers + register attention 压缩跨帧信息交换,用单一 dense depth head 加 training-only point/matching losses 省掉冗余头,再用大规模视频标注管线和 teacher-student 自监督扩数据。

效果. 训练显存约降到 VGGT 的 30%,监督数据扩大到 15x 以上,在静态和动态 6 个 benchmark 上刷新 camera/depth 结果;Sintel camera AUC@3° 从 22.5 提到 40.0,相对提升 77%。

代价. 结果强依赖内部数据、128 张 96GB H100、大规模伪标注过滤和 10B 模型;论文 preview 版尚未给出完整代码细节,复现门槛非常高。

§ 1 · POSITIONING

论文定位:从重建器到几何基础模型

VGGT-Ω 处在 feed-forward 3D reconstruction 这条线上。输入是一组图像或视频帧,模型不跑 SfM/MVS 的迭代优化,而是一次 transformer forward 直接输出每帧相机和深度。它继承 VGGT 的核心范式:把多视角几何估计做成一个可训练的大模型。

与传统 COLMAP、bundle adjustment、MegaSaM 这类方法相比,关键差异不是“更换一个优化器”,而是把几何推断从测试时优化搬到训练时学习。推理时不需要显式匹配、三角化、BA 循环,而是依赖大规模数据学到的几何先验。

与 VGGT 相比,VGGT-Ω 的核心不是单点提升,而是三个层面的 scaling recipe:架构层面省显存,数据层面扩大到动态视频,训练层面引入未标注视频自监督。论文真正的 insight 是:前馈重建模型可能像语言模型一样有比较稳定的 scaling law,并且中间的 scene registers 可以成为通用空间表征。

Baseline Paradigm

传统几何 / 优化式动态重建

  • 依赖特征匹配、RANSAC、三角化、bundle adjustment
  • 在 well-conditioned 静态场景可极准,但动态、弱纹理、少视差会崩
  • 测试时计算重,很难直接变成可迁移的空间 token
VGGT-Ω Paradigm

大模型前馈几何

  • 一次 forward 输出 camera + depth
  • 用动态和静态大数据学习几何先验
  • scene registers 同时是跨帧通信瓶颈和下游空间表征
这篇论文的主张是:3D 重建不只是一个输出点云的工具,也可以成为训练空间智能表征的 proxy task。
§ 2 · PIPELINE

方法总览:一条更可扩展的 VGGT

宏观上,VGGT-Ω 的 pipeline 可以压缩成 6 步:

  1. 输入 $N$ 张图像或视频帧,不显式依赖时间顺序。
  2. DINOv3 ViT 把每帧切成 patch tokens。
  3. 每帧追加 1 个 camera token 和 16 个 scene registers。
  4. 多层 alternating attention 在帧内和跨帧之间传播信息;其中 25% 的 global attention 被 register attention 替代。
  5. depth head 输出每帧 depth/confidence;camera head 从 camera token + registers 输出 9D camera 参数。
  6. 训练时额外用 point loss 和 matching loss 监督 latent,但推理时不输出 point map 和 tracking head。

§ 3 · INNOVATIONS

关键创新点:三个省钱设计加两个扩数据设计

创新 1

Register attention: 把跨帧通信压缩到 scene tokens

旧瓶颈. VGGT 的 global attention 让所有帧的所有 patch tokens 互相看见,复杂度随总 token 数二次增长。长视频、多帧输入、训练反传都会被 attention activation 卡住。

怎么改. VGGT-Ω 观察到 VGGT 中 global attention map 很稀疏,于是把部分 global layers 改成 register attention:跨帧 self-attention 只发生在每帧的 16 个 registers 之间,patch tokens 不直接跨帧通信。

为什么有效. 如果多视角几何需要的是少量全局 scene state,那么 registers 可以当信息瓶颈:先收集各帧信息,再通过后续 frame attention 把全局信息回写到本帧 patch tokens。它类似一个可学习的多视角工作记忆。

代价. 只替换 25% global layers 基本不掉性能;全部替换会把 FLOPs 降到约 6%,但性能掉回 VGGT 水平。说明 registers 不是万能总线,高精度几何仍需要一部分 dense cross-frame interaction。

创新 2

单 dense head + 多任务 loss: 不输出也能监督

旧瓶颈. VGGT 有多个 dense prediction heads,例如 depth、point map、tracking features。多头训练确实有益,但高分辨率 dense head 的 forward activations 极其吃显存,FSDP 和 checkpointing 也不能消掉这类激活存储。

怎么改. VGGT-Ω 推理时只保留 depth dense head 和 sparse camera head,但训练时通过 camera、depth、point、matching 四类 loss 继续给 latent 施加几何监督。point map 由 depth + camera 反投影得到,matching loss 直接作用在最后一层 tokens。

为什么有效. 监督信号和输出头被解耦了。模型仍然被迫学习点级几何和跨帧匹配,但不需要维护多个昂贵 dense decoders。

代价. 原 VGGT 多头多任务的 point error 可到 0.070,VGGT-Ω 的单头多 loss 为 0.073,略差但可扩展。去掉 point/matching losses 后升到 0.078,说明这些 training-only losses 仍然有必要。

创新 3

MLP + pixel shuffle: 针对 dense decoder 的显存手术

旧瓶颈. DPT head 的高分辨率卷积层参数不多,但 activation 大,训练时很贵。

怎么改. 在超过输入 1/4 分辨率的部分,用一个 MLP 输出 $2u^2$ 个通道,再用 pixel shuffle 变成 $(uH')\\times(uW')\\times2$。论文实现里 $u=4$,两个通道对应 depth 和 confidence。

为什么有效. Pixel shuffle 把空间上采样变成通道重排,避免维护多个高分辨率卷积特征图。低分辨率卷积仍保留,用于减少纯 MLP depth 的 block artifacts。

代价. 完全去卷积的 decoder 定量不差,但户外远景会出现块状伪影。几何输出不像图像像素那样数值有界,纯 token-to-pixel MLP 更难保证空间平滑。

创新 4

动态视频标注管线: 先保守过滤,再大规模伪标注

旧瓶颈. 动态视频是最大的数据源,但传统 SfM/MVS 假设场景静态。直接用互联网视频做监督会把镜头切换、运动模糊、反光、纯旋转、动态物体等噪声注入模型。

怎么改. 论文构建约 4000 万内部视频池:VLM 先做 hard/soft reject 和动态性判断;Grounding DINO 掩掉人、车等可动物体;SuperPoint/SuperGlue、ALIKED/LightGlue、VGGSfM Tracker 做匹配和 track;VGGT 初始化困难相机;COLMAP 做 BA;再用多视角一致性和监督几何分类器过滤。

为什么有效. 这条线的策略不是最大化样本数,而是最大化 pseudo GT 置信度。论文最终保留约 60 万静态和 20 万动态高质量视频序列,再和其他数据合成总计约 400 万 scenes/sequences。

代价. 这部分是最大复现门槛。VLM、内部视频、人工标注 1000 条过滤器训练集、多个 matcher 和 SfM/MVS 工具链都要稳定协同。

创新 5

Teacher-student 自监督: 用未标注视频学不变性

旧瓶颈. 监督重建数据昂贵,而视频海量。直接新视角合成或从零自监督在动态场景上并不稳。

怎么改. 从 supervised VGGT-Ω checkpoint 初始化 teacher/student。对同一帧集合施加不同增强和随机帧重排,恢复共同顺序后,student 匹配 teacher 的多层 tokens、camera 和 depth;teacher 用 EMA 更新,heads 在自监督阶段冻结防坍塌。

为什么有效. 它没有要求像素级重建,而是把已经学到的几何函数蒸馏成对颜色扰动、遮挡、旋转、帧顺序更稳定的表征。论文用 1800 万未标注视频,自监督替换 10% supervised steps 后 point error 从 0.073 到 0.070。

代价. 作者自己承认其他自监督方案基本没打通;这套 teacher-student 仍依赖一个强 supervised checkpoint,不是完全从零的自监督 4D 重建。

§ 5 · FORMULAS

公式和算法:把关键 5 个式子拆开

Formula 1 · Problem Formulation

$$((g_1,D_1),\\ldots,(g_N,D_N))=f(I_1,\\ldots,I_N)$$ $$D_i\\in\\mathbb{R}^{H\\times W},\\quad g_i=(q_i,t_i,f_i)\\in\\mathbb{R}^{9}$$
这里 $q_i\\in R^4$ 是 rotation quaternion,$t_i\\in R^3$ 是 translation,$f_i\\in R^2$ 是 field of view。论文默认 principal point 在图像中心。实现中就是每帧预测一个 9D pose encoding 和一张 dense depth。

Formula 2 · Tokenization

$$z_i^F=DINOv3(I_i)\\in\\mathbb{R}^{H'W'\\times C},\\quad H'=H/r,\\ W'=W/r$$ $$z_i=(z_i^F,z_i^{cam},z_i^{scene}),\\quad z\\in\\mathbb{R}^{N\\times(H'W'+17)\\times C}$$
每帧 1 个 camera token 和 16 个 scene tokens。$17=1+16$。训练和推理都不需要显式 frame index embedding,只区分 reference/non-reference token 参数。

Formula 3 · Register Attention

$$\\left(z_1^{scene'},\\ldots,z_N^{scene'}\\right)=attn\\left(z_1^{scene},\\ldots,z_N^{scene}\\right)$$
普通 global attention 是所有帧所有 tokens 相互 attention。Register attention 只更新各帧 registers,再依赖后续 frame attention 把 scene-level 信息回写给 patch tokens。论文默认只替换 25% global attention layers。

Formula 4 · Multi-task Training Loss

$$\\mathcal{L}=\\lambda_{cam}\\mathcal{L}_{cam}+\\lambda_{depth}\\mathcal{L}_{depth}+\\lambda_{point}\\mathcal{L}_{point}+\\lambda_{match}\\mathcal{L}_{match}$$ $$\\lambda_{cam}=5.0,\\quad \\lambda_{depth}=1.0,\\quad \\lambda_{point}=0.5,\\quad \\lambda_{match}=0.1$$
$\\mathcal{L}_{cam}$ 是 camera L1。$\\mathcal{L}_{point}$ 不需要额外 point head,而是用 $\\pi^{-1}(\\hat D_i,\\hat g_i)$ 反投影后和 GT point map 比。这个设计是省显存的关键。

Formula 5 · Matching Loss and EMA Teacher

$$\\mathcal{L}_{match}=\\mathbb{E}_{pos}[-\\log\\sigma(s)]+\\mathbb{E}_{neg}[-\\log(1-\\sigma(s))]$$ $$\\theta_T\\leftarrow m\\theta_T+(1-m)\\theta_S,\\quad m=0.999$$
$s$ 是 L2-normalized tokens 的 cosine similarity。Positive pairs 来自跨视角投影重叠超过阈值的 patches;negative pairs 同时满足 epipolar/Sampson 距离大和 RGB appearance 差异大。EMA teacher 用于未标注视频蒸馏。
实现提醒

最容易写错的是 reference frame 和归一化

论文训练时会把 GT 变换到第一相机坐标系,再用所有 3D 点到原点的平均距离做 unit-space scale normalization;这个 normalization 只作用于 GT,不直接 normalize predictions。实现里如果把 prediction 也在线 normalize,训练曲线会更陡,也更容易 gradient explosion。

Critical Reading

公平性和 confound

  • Ours-10B 对很多 baseline 有明显参数和数据优势
  • 4M 标注池、18M 未标注视频和内部数据不可复现
  • 伪标注质量评估只在过滤后的 Sintel 子集上做,偏乐观
  • 随机 10 帧评估不等同于长视频 SLAM 或闭环场景
  • 动态区域被过滤或依赖 synthetic,真实复杂非刚体仍可能不足
论文最强的证据不是某一个表格,而是 scaling curve、memory ablation、动态/静态 benchmark 和 register 下游应用同时指向同一个结论:学几何的 transformer 正在变成空间表征模型。
§ 8 · REPRODUCTION

可复现清单:真正会卡住的地方

模型规模. 论文用 200M/500M/1B/10B 四档。Blocks/hidden sizes 分别为 12/12/24/16 和 384/768/1024/4096。10B 不是个人工作站级别。
训练硬件. 主训练使用 128 张 96GB H100,bfloat16,FSDP,gradient checkpointing。小规模复现应先从 200M 或 1B 子集开始。
学习率. AdamW,总 240K steps:160K supervised,50K self-supervised,30K supervised。Warmup 5%,cosine decay;监督 peak LR 2e-4,自监督 1e-4。

§ 10 · MEMORY CARD

速读备忘卡:下次回忆用

  • VGGT-Ω 是 VGGT 的 scaling 版本,核心不是一个模块,而是架构 + 数据 + 自监督 + 下游表征的系统升级。
  • 输入 $N$ 帧,输出每帧 camera 9D 和 depth map;不直接输出 point map/tracks。
  • 每帧加 1 个 camera token 和 16 个 scene registers。
  • Register attention 只让 registers 跨帧通信,替换 25% global attention 基本不掉点。
  • 单 dense head 保留 depth/confidence,point 和 matching 变成 training-only losses。
  • 高分辨率 DPT conv 被 MLP + pixel shuffle 替换,训练显存降到 VGGT 约 30%。
  • 数据管线核心是保守过滤:4000 万视频进来,最后留约 80 万高质量真实视频标注。
  • 自监督不是从零学几何,而是强 supervised checkpoint 的 teacher-student consistency。
  • Sintel camera AUC@3° 从 22.5 到 40.0;depth δ1.25 从 86.1 到 93.5。
  • Registers 能加到 OpenVLA-OFT,LIBERO 平均 SR 从 97.1 到 98.5。
  • 最大限制是复现门槛:内部数据、巨大算力、复杂伪标注和 preview 版代码缺口。
  • 最值得带走的 insight:重建模型的中间 token 可能是通用空间智能的底座,不只是点云输出。
