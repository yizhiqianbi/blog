World Model 02

VLA 策略：把大模型具身化

VLA 是这组笔记的入口，但它本身不是世界模型。它回答“现在该输出什么动作”， 后续世界模型路线则试图把“动作会导致什么后果”显式或隐式塞回策略。

2026.05.12 阅读约 7 分钟

两条主线

视觉运动策略可以直接回归动作，也可以用 Diffusion 或 Flow 生成多模态动作。VLA 则把视觉、语言、 动作放进预训练 VLM 的语义空间里：RT-2 走动作 token 化，OpenVLA 把这条路线开源化， pi0 使用 flow matching 输出连续动作。 

机器人策略学习
    ├── Visuomotor Policy
    │   ├── regression: simple, fast, often unimodal
    │   └── diffusion / flow: multimodal, needs acceleration
    └── VLA Policy
        ├── discrete action tokens
        └── continuous action flow

代码视角

离散 VLA 把 action 当语言 token 生成，连续 VLA 通常保留 VLM encoder， 再挂一个 action head 或 flow head。二者的分歧本质是动作空间如何表示。 

hidden = vlm.encode(image=obs.rgb, text=instruction)

if action_space == "discrete":
    action_tokens = lm_head.generate(hidden)
    action = detokenize_action(action_tokens)
else:
    noise = sample_normal(shape=(horizon, action_dim))
    action = flow_head.sample(hidden, proprio=obs.proprio, noise=noise)

实现重点

  • 动作离散化能复用语言模型训练范式，但要处理高频控制和连续精度损失。
  • 连续 flow head 保留原始动作结构，更适合双臂和灵巧操作，但训练和推理要照顾控制频率。
  • Open X-Embodiment 这类多机器人数据集解决的是 coverage，不自动解决 action normalization 和 embodiment gap。

Insight

VLA 强在语义迁移，不强在物理后果建模。它让机器人“听懂任务”，但未必知道候选动作会让场景怎么变。 世界模型路线正是在补这一块。
